# 效果评估

工程测试回答“协议与流程是否正确”，真实生成评估回答“这个案例中多视角是否产生了价值”。两者不能互相替代。

## 可复现案例

[`examples/pilot-decision.json`](../../examples/pilot-decision.json) 是无私人信息的产品选择案例。把 problem/context 交给 begin，由同一宿主和同一模型完成 3+3+1 独立生成，保留每轮产物供人工复核。

## 观察什么

1. 三家是否各有具体、独立的判断，而不是换词重复。
2. 质询是否指出其他方略的前提、缺口或风险，而不是客套式赞同。
3. 贾诩是否在已知信息内作出明确选择，并指出方案最脆弱的一环。
4. 是否完整执行三拍，保持同模型、上下文隔离，无额外讨论轮。

这是评估准则，不进入角色提示词，也不作为强制回答模板。

## 记录条件

记录日期、项目版本、宿主版本、模型、输入、耗时和实际生成结果。区分工具确实禁用与仅在提示词中要求不用工具；区分独立实例与同一对话中的角色扮演。若有失败，记录真实原因，不补写“成功”案例。

需要比较效果时，用同一问题、同一模型、相同背景做独立基线，并对匿名结果进行人工盲评；单次案例只能证明该次执行情况，不能支持“普遍优于单模型”的结论。原始运行日志可能含本机路径或账号信息，不提交仓库。
