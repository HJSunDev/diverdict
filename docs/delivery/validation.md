## Codex 真实生成案例

使用上述桌面内置运行时、GPT-6 Astra 和公开的两人团队试点案例，完成三次 MCP 调用和七个真实生成任务。三个工具均返回 completed，进程以 0 退出，最终收到贾诩方略。原文示例见 [pilot-result.md](pilot-result.md)。本机此次执行约 13 分半，不作为通用性能基准。

第一轮三家都倾向受限试点，但对收费门槛、外部客户验证时点和发布安排有不同判断。质询明确攻击了“口头购买意愿放行下一笔投入”“采购时钟与六周期限冲突”“人工支持掩盖真实产品成本”等前提。最终方略选择先做受限试点、第一周同步接触局外客户、按真实交易与支持成本决定后续投入，并指出六周能否容纳采购和使用周期是最脆弱的一环。

**调度观察：** 宿主报告第二轮逐个启动任务时，首个实例在全部任务启动前已经完成，因此这次案例不能证明三个实例的运行区间完全重叠。保留该事实，未将其改写为严格同时启动的成功案例。交付版宿主指令已明确“同轮先全部派发，再统一等待和收集”；这属于原有并行规则的说明，不是新增轮次或执行机制。调度仍由宿主实现，服务没有加入自报机制或审计工具。

本次记录支持“Codex 工具闭环及真实产物已验证”，不支持跨模型效果优越性、所有宿主的能力保证，或宿主底层权限已经经过独立审计的结论。
